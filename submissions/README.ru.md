# Пакет Для Подачи Предложения

Цель пакета: подать предложение о едином открытом API-профиле для участников инфраструктуры обращения цифровой валюты по законопроекту N 1194918-8 и связанным подзаконным актам.

Важно: тексты ниже не продвигают монополию конкретной библиотеки. Они предлагают открытые требования к API, тестовый контур и reference implementation как добровольную техническую основу для пилота и обсуждения.

## Куда Подавать

| Адресат | Канал | Что отправлять |
| --- | --- | --- |
| Государственная Дума | https://priemnaya.duma.gov.ru/ru/message/ | `appeal-duma.ru.md` + приложение |
| Банк России | https://www.cbr.ru/reception/ | `appeal-cbr.ru.md` + приложение |
| Минфин России | https://minfin.gov.ru/ru/appeal/ или официальный канал обращений через Госуслуги | `appeal-minfin.ru.md` + приложение |

## Почему Тексты Разные

В Госдуму лучше писать как законодательное предложение: нужна норма и обоснование для законопроекта.

В Банк России лучше писать как предложение о подзаконном техническом профиле: API-требования, тестовый контур, conformance tests, безопасность.

В Минфин лучше писать как предложение для финансово-экономической и правовой доработки: снижение стоимости интеграций, технологический суверенитет, отсутствие частной монополии.

## Что Заполнить Перед Отправкой

В конце каждого обращения заменить:

- `[ФИО]`;
- `[город]`;
- `[email]`;
- `[телефон]`;
- `[дата]`.

Если нет телефона или не хочешь его указывать, лучше оставить только email, если форма допускает.

## Самопроверка

- В теме есть номер законопроекта: `1194918-8`.
- Не написано "обязать использовать мою библиотеку".
- Написано "единый открытый API-профиль", "reference implementation", "conformance tests".
- Ясно сказано, что открытой должна быть спецификация, а доступ к данным остается защищенным и авторизованным.
- Есть тестовый контур до начала оказания услуг клиентам.
- Есть роль Банка России в утверждении технических требований.
- Есть исключение для сведений, составляющих охраняемую законом тайну или создающих риски ИБ.
- В конце заполнены ФИО, город, email, телефон, дата.
